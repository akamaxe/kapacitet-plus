# Versions of the project's own virtual environment (.venv), resolved 2026-11-06.
#
# The project has its own environment because the base Anaconda env drifted to pandas 3.0 and
# scipy 1.18 (2026-10-09), and the engine needs a combination every package declares as supported:
#
#     python -m venv .venv
#     .venv/Scripts/python -m pip install -c constraints.txt -e ".[dev]"
#
# Until 2026-11-06 that combination was pandapower 2.14 with numpy below 2 and scipy below 1.14,
# the only line pandapower 2.14 supports. It now is pandapower 3.5, whose own ceilings set the rest:
#
# - numpy 2.4: pandapower 3.5 declares numpy below 2.5.
# - scipy 1.18: pandapower 3.5 requires scipy 1.15 or later and sets no ceiling.
# - pandas 2.3: pandapower 3.5 declares pandas ~=2.3, so not pandas 3, whose mandatory
#   copy-on-write still conflicts with how it writes result tables.
# - networkx 3.7: pandapower 3.5 declares networkx ~=3.6.
# - cvxpy 1.9: from 1.8 on it requires numpy 2, which is now the case.
# - pyarrow 26: past the 23.0.1 fix of GHSA-rgxp-2hwp-jwgg, so the audit needs no ignore.
# - duckdb stays on 1.5: 2.0 is a major version, a decision of its own.
# - lxml 6.1: pandapower 3's CGMES converter needs it and no longer brings it along (it sits in
#   pandapower's `converter` extra, with pypowsybl, which the project does not use).
